# Vocal Finish

Singer-focused vocal finishing plugin prototype by Edren Audio.

## V1 goals
- Fast vibe-based vocal finishing
- Seven macro controls: Clean, Tight, Smooth, Warmth, Air, Space, Width
- Presets for common lead/background vocal directions
- Simple gray hardware/rack-style interface
- Stable, versioned DSP development so approved processing stages stay locked

## Run locally
```bash
npm install
npm run dev
```

Current build is a browser DSP prototype. Native VST3 packaging will come after the processing chain is approved.
